# 百炼 Agent 搭建步骤（低代码版）

> 目标：不写复杂后端，先把「随行讲解员」在阿里云百炼里跑通。  
> 当前 MVP：先用故宫太和殿、秦始皇兵马俑、杭州西湖 3 个景点跑通，再扩展。  
> 说明：百炼界面会更新，以下路径以当前实际界面为准；如果菜单名称不同，按“创建智能体 / 应用 / Managed Agent”的关键词找。

## 第 0 步：准备账号和材料

- [ ] 阿里云账号（注册并认证）
- [ ] 百炼控制台访问权限
- [ ] 飞猪 FlyAI 开放平台账号
- [ ] GitHub 账号和公开仓库
- [ ] `prompts/system-prompt.md`
- [ ] `knowledge/` 中的 3 个 MVP 景点文件
- [ ] 3 个景点各 3 张测试图片

## 第 1 步：创建百炼 Managed Agent

1. 登录[阿里云百炼控制台](https://bailian.console.aliyun.com/)。
2. 进入“模型广场”或“应用 / 智能体”页面。
3. 选择 **Managed Agent**。
4. 新建智能体，名称填：`随行讲解员`。
5. 模型选择：
   - 主模型：**Qwen-VL**（支持图片输入）
   - 如平台需要单独配置文本模型：再选 **Qwen-Plus** 或 **Qwen-Max**
6. 保存后，进入智能体编辑页。

## 第 2 步：粘贴系统提示词

1. 找到“人设 / 系统提示词 / Instructions”。
2. 打开 `system-prompt.md`，从头到尾复制。
3. 粘贴进系统提示词输入框。
4. 把【我的知识库：请填入知识库名称】替换成你实际创建的知识库名称。
5. 保存。

## 第 3 步：安装飞猪官方 Skill

在智能体会话或平台的“技能 / Skill / 工具”配置中，执行：

```bash
npx skills add alibaba-flyai/flyai-skill
```

如果平台没有命令输入框，去[飞猪 AI 开放平台](https://flyai.open.fliggy.com/)查看当前推荐的安装方式，并按平台说明接入。

安装完成后，确认智能体可以调用：

- `keyword-search`
- `ai-search`
- `search-poi`
- `search-hotel`
- `search-flight`

## 第 4 步：申请并配置 FlyAI API Key

1. 打开[飞猪 FlyAI 开放平台](https://flyai.open.fliggy.com/)。
2. 登录后进入控制台，申请 API Key。
3. 在百炼智能体的“环境变量 / 工具配置”中添加：

```bash
FLYAI_API_KEY=你的APIKey
```

4. 不要把 API Key 写进 GitHub 仓库、截图或视频。

**调用额度参考**：
- 访客：总共 300 次
- 注册用户：送 5000 次，用完后每天补 100 次
- 更多额度：加入大赛交流群，按官方说明申请

## 第 5 步：创建知识库

1. 在百炼中找到“知识库 / 数据 / 知识”入口。
2. 新建知识库，名称例如：`随行讲解员-10景点`。
3. 按 `demo-spots.md` 中的 10 个景点，每个景点一个 Markdown 文件。
4. 上传或粘贴到知识库。
5. 保存并命中测试：
   - 问：“太和殿有哪些史实？”
   - 问：“雷峰塔有什么传说？”
   - 问：“莫高窟始建于什么时候？”
6. 如果知识库功能不可用，兜底方案：
   - 把 10 个景点的关键内容精简后直接放进系统提示词。
   - 或者只做 3 个景点，保证内容可控。

## 第 6 步：第一次端到端测试

按顺序测试：

- [ ] 上传太和殿图片，确认能识别出“故宫·太和殿”。
- [ ] 选择“3 分钟标准版”，确认有完整讲解。
- [ ] 确认输出包含【史实】【传说】【待考证】。
- [ ] 确认有来源。
- [ ] 追问“带孩子怎么讲？”，确认切换儿童版。
- [ ] 上传兵马俑图片，确认识别正确。
- [ ] 追问“附近还有什么值得看？”，确认调用 FlyAI 并返回真实结果。
- [ ] 追问“怎么订票？”，确认返回 `jumpUrl`。
- [ ] 上传一张无关图片，确认 Agent 会承认无法识别，而不是编造。

## 第 7 步：做缓存，控制额度

建议提前跑好并保存以下内容：

- 10 个景点的标准讲解文本、儿童版、故事版。
- 10 组 FlyAI 查询结果（POI、门票、jumpUrl）。
- 3–5 张演示图片和对应识别结果。

这样录视频时可以避免网络不稳定或额度不够。

## 常见问题

### 1. 图片识别不出来怎么办？

- 换更清晰的图片。
- 先用文字输入确认知识库内容正常。
- 在提示词中已要求“不猜测”，所以识别失败时让它追问是正常行为。

### 2. FlyAI 没有返回结果怎么办？

- 检查 API Key 是否配置正确。
- 检查城市名是否用中文全称，例如“北京”，不要写“BJ”。
- 检查日期是否为未来日期。
- 换更常见的查询词，例如“北京 故宫 门票”。

### 3. 回答开始胡编历史怎么办？

- 确认知识库已命中。
- 在系统提示词中再次强调：没有来源必须写【待考证】。
- 用测试问题清单逐项检查，发现问题就补充知识库文件。

### 4. 平台没有 `npx` 命令怎么办？

- 按飞猪 AI 开放平台当前文档操作，或使用平台提供的 Skill 市场直接安装。
- 如果仍无法安装，先用文字查询能力演示，并在提交材料中说明接入方式。
