## 旅行场景与目标用户

面向**自由行游客、亲子家庭和入境游客**，解决景区、博物馆、历史街区“看不懂、请导游贵、网上讲解千篇一律”的问题。

典型场景：
- 自由行游客拍下一张景点照片，希望马上知道它是什么、有什么故事。
- 家长希望用孩子能听懂的方式讲解历史和文化。
- 入境游客需要跨文化的景点讲解和下一步旅行建议。

## 我做了什么

【待补：只写你真实完成的功能。可以参考下面的表述，做完哪条写哪条。】

- **拍景点讲解**：上传景点/文物照片后，使用 Qwen-VL 识别景点，并给出置信度和识别依据。
- **拍牌匾/说明牌**：识别牌匾、楹联、说明牌或外文标识，解释文字含义和背景。
- **结构化讲解**：关键结论标注【史实】【传说】【待考证】，并附来源和置信度。
- **低置信度兜底**：识别不确定时给出 2–3 个候选让用户确认，不硬猜。
- **多档讲解与追问**：生成 1/3/5 分钟讲解，支持儿童版、专业版、故事版，可多轮追问。
- **亲子任务卡**：讲解后自动生成观察任务和思考问题。
- **真实行动闭环**：通过飞猪 FlyAI 查询附近 POI、门票和玩乐，并给出可点击的 `jumpUrl`。
