# 测试用例

> 每次修改提示词或知识库后，按本清单回归测试。  
> 目标：保证“拍照 → 识别 → 分层讲解 → 来源 → 亲子任务 → FlyAI 推荐”整条链路稳定。

## 三、完整链路测试

| 编号 | 步骤 | 期望 | 通过 |

## 四、评分标准

| 项目 | 目标 |
|---|---|
| 识别准确率 | 3 个 MVP 景点 ≥ 90% |
| 分层完整率 | ≥ 95% 的讲解包含主张、类型、来源、置信度 |
| 亲子任务可用率 | ≥ 90% |
| FlyAI 查询成功率 | ≥ 90% |
| 平均响应时间 | ≤ 8 秒 |
| 严重事实错误 | 0 个 |
