## 使用方式

1. 在百炼中创建知识库，例如 `随行讲解员-3景点`。
2. 将本目录中的 Markdown 文件上传或粘贴进去。
3. 在系统提示词中把知识库名称改成实际名称。
4. 用测试问题逐条验证知识库是否命中。

## 文件规范

每个景点文件统一包含：

- 识别特征
- 史实
- 传说
- 待考证
- 来源
- FlyAI 查询示例
- 亲子任务卡示例

可以直接复制 [`_template.md`](_template.md) 新建景点。
